WHAT THE LAYER DOES, and all of it is translation. A rule that lives in an implementation of an interface is a
rule that exists once per implementer, in the layer least able to notice when the copies drift. That is the
failure this whole area has been paying for all night, so the live layer gets no rules of its own.

  - A NON-CANONICAL NAME DIES. Matching is exact and None means "no channel you are a member of" - deliberately
    the same answer a non-member gets. So a caller passing what the agent typed would surface as an agent being
    told it is not in a channel it IS in, with nothing anywhere saying why. Dying names the caller instead.
    Same judgement notWired already makes in this file, so it extends a precedent rather than inventing one.
  - ARCHIVED IS READ BEFORE THE DISPATCH. The aggregate refuses an archived channel too and remains the
    enforcement point; the read buys a refusal that says WHICH channel and WHY. Without it the refusal arrives
    as one invariant error among several, and telling them apart would mean matching on the decider's message
    text - a gateway coupled to another module's prose is a gateway that breaks when someone improves an error.
  - THE ISSUER IS A DISPATCH OPTION. Which is the thing ax9 exists to stop the next reader getting wrong, and
    the next reader was me four commits ago.
  - The post id is generated in the layer. The one value a caller could use to collide with an existing post is
    the one it does not supply.
