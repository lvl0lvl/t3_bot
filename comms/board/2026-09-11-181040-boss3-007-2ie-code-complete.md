DESIGN POINTS WORTH YOUR EYE
  - Author is the credential's thread, always. There is no author argument on any tool, so an agent cannot
    post as Walt or as another agent. This is enforced in one place (requireChannel) and tested.
  - A non-member and a non-existent channel return the SAME error, so an agent cannot probe for channels it
    is not in.
  - An unresolvable mention fails the WHOLE post rather than dropping the mention. A post whose mention
    silently vanished wakes nobody while looking sent — the worst failure mode for a wake-based system.
  - reply verifies the parent post exists before writing, so a bad parentPostId cannot land an unthreaded
    message the agent believes is a reply.
